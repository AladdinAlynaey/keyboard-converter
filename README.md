<p align="center"><a href="#arabic">العربية</a> · <b>English</b></p>

<img src=".github/assets/hero-en.jpg" alt="Keyboard Converter: instantly fixes text typed in the wrong keyboard layout, with AI if you like." width="100%">

<br>

A single-page app that instantly converts text typed in the wrong keyboard layout, English to Arabic and back, on every keypress without waiting for the server. On top: three AI modes for checking and translating, a layout map editor, and a marketplace where people publish, rate and comment on layouts.

<br>

<img src=".github/assets/architecture-en.jpg" alt="How it works: conversion in the browser; the server keeps layouts in MongoDB and runs OpenRouter and email." width="100%">

<img src=".github/assets/flow-en.jpg" alt="From wrong letters to the right text: instant conversion, plain or smart mode, history, then the marketplace." width="100%">

<img src=".github/assets/atlas-en.jpg" alt="What it offers: twelve capabilities from instant conversion to design." width="100%">

<img src=".github/assets/library-en.jpg" alt="Code and security: 9,141 lines of code by layer, and five security rules." width="100%">

## Running it

```bash
pip install -r requirements.txt
python app.py
```

Or with containers: `docker compose up -d`. The full guide is in [`docs/GUIDE.md`](docs/GUIDE.md): repository map, security, setup, Docker, PM2 and Nginx.
